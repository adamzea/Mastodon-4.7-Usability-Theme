# Mastodon-4.7-Usability-Theme
CSS code to copy/paste into the Advanced CSS field in order to improve usability.  This will fix the mystery meat navigation on mobile, make dark mode add true black in order to save battery on OLED screens, and add some nice "acrylic" style backdrop filter effects to both dark mode and light mode. Weirdly, the default styles had backdrop filters applied to many areas, but their effects were not visible since the default background colors had no transparency.

This also replaces the Mastodon logo with "Lein Social". You can edit that to show the name of your server on line 5 of the advanced.css file.
